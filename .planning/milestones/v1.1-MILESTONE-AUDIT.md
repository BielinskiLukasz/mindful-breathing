## Tech Debt (Non-Blocking)

### Phase 07 — CSS Regressions (Carry-Forward from Code Review)

**WR-01 — Transition shorthand strips existing transitions**  
File: `index.html` — hover states CSS block (~line 1253)  
Impact: On desktop (pointer:fine), theme switches and preset highlight changes snap instead of fading.  
Fix: Merge all five transition properties into the hover media query rule instead of using shorthand.

**WR-02 — Hover transform overrides active transform**  
File: `index.html` (~line 1260)  
Impact: `button:hover { transform: scale(1.02) }` overrides `button:active { transform: scale(0.97) }` at equal specificity. Click press-down animation broken on desktop.  
Fix: Change to `button:hover:not(:active) { transform: scale(1.02) }`.

### Phase 08 — Accessibility Warning

**statusText aria-live gap**  
File: `index.html:2297`  
Impact: `statusText.textContent` updates without `aria-live`. This is a soft warning — A11Y-02 is covered by the `#announcer` element and `#phase aria-live`. No REQUIREMENTS.md gap, but defensive coverage could be improved.
