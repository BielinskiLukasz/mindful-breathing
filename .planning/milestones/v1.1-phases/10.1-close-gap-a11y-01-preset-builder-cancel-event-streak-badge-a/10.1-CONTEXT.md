<domain>
## Phase Boundary

Surgical integration gap closure: two bugs identified by the v1.1 milestone audit.

1. **A11Y-01 blocker** — `presetBuilderDialog` (native HTML `<dialog>`) does not listen for the `cancel` event. When user presses Escape, the browser closes the dialog natively but `openPanelElement` is not reset to `null`. Keyboard shortcuts (Space/R/F) remain blocked until page reload.

2. **Streak badge stale after import** — `importJson()` and `importCsv()` call `renderHistory()` but not `updateStreakBadge()`, `updateStreakPanel()`, or `maybeUpdateLongestStreak()`. Streak display is stale until reload or next session.

No new features. No UI design. No structural changes.

</domain>

<decisions>
## Implementation Decisions

### Fix 1: Preset Builder Escape / Cancel Event

- **D-01:** Add `presetBuilderDialog.addEventListener("cancel", ...)` to handle native dialog Escape. This is the correct fix — `presetBuilderDialog` is a `<dialog>` element; the browser fires `cancel` before the keydown handler sees Escape for native dialogs.
- **D-02:** The `cancel` handler must: set `openPanelElement = null` AND call `document.getElementById("newPresetBtn")?.focus()`.
- **D-03:** Focus returns to `newPresetBtn` — consistent with all other panels (closeInfo → infoBtn, closeStreak → streakBtn, closeSettings → settingsBtn).
- **D-04:** Do NOT add an Escape branch in the keydown handler for `presetBuilderDialog` — the `cancel` event listener is sufficient and cleaner for `<dialog>` elements.

### Fix 2: Streak Update After Import

- **D-05:** After `renderHistory()` in both `importJson()` and `importCsv()`, add three calls in order:
  1. `updateStreakBadge()`
  2. `updateStreakPanel()`
  3. `maybeUpdateLongestStreak()`
- **D-06:** `maybeUpdateLongestStreak()` is included because importing historical sessions could reveal a streak longer than the current persisted high-water mark. Consistent with the two-tier design from Phase 10.
- **D-07:** Call order matches the existing pattern used at session end (lines 3070–3072 in index.html) and at startup (lines 3609–3610).

### Claude's Discretion

- Exact placement of the `cancel` event listener in the CUSTOM PRESET BUILDER section — near the existing `presetBuilderDialog.close()` calls for readability.

</decisions>
