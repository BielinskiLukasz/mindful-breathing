**PART F: Add buildActivePhases() function**

Add after updateModeIndicator() (line ~1585):

```javascript
function buildActivePhases() {
  if (activePresetKey in PRESETS) {
    // Built-in preset: use directly
    activePhases = PRESETS[activePresetKey].map(p => ({...p}));
  } else {
    // Custom preset: lookup and build from phases array
    const customPreset = customPresets.find(p => p.id === activePresetKey);
    if (customPreset) {
      activePhases = customPreset.phases
        .filter(p => p.active) // Only active phases
        .map(p => {
          // Lookup phase type in PRESETS to get theme, breathR, cue
          const basePhase = PRESETS.relax.find(bp => bp.name === p.type);
          return {
            name: p.type,
            durationSec: p.durationSec,
            breathR: basePhase.breathR,
            theme: basePhase.theme,
            cue: basePhase.cue,
            hint: basePhase.hint
          };
        });
    } else {
      // Fallback: use Relax
      activePhases = PRESETS.relax.map(p => ({...p}));
      activePresetKey = "relax";
    }
  }
}
```

This function:
- Checks if activePresetKey is in PRESETS (built-in)
- If yes: copy the preset phases directly
- If no: lookup custom preset, filter to active phases only, and build phase objects by looking up phase type in PRESETS for theme/breathR/cue
