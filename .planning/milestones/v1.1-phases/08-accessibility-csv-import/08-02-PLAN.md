## Trust Boundaries

| Boundary | Description | Threat |
|----------|-------------|--------|
| Keyboard handler → Global state | Handler reads `openPanelElement` state | State mismatch; shortcut fires when panel is open |
| Focus trap → DOM | Tab navigation cycles focus within panel | Focus escapes to background; user loses control |
| CSV parser → localStorage | Imported CSV data written to history | Data corruption; duplicate/invalid sessions; quota exceeded |
| File input → FileReader | User-supplied CSV file | Oversized file; malformed content; encoding issues |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-07 | Tampering | Keyboard shortcut guard (anyPanelOpen state) | medium | mitigate | Guard check is immediate (boolean); state set/cleared by panel open/close functions; state mismatch impossible if panel functions properly |
| T-08-08 | Denial of Service | Focus trap infinite loop on Tab | medium | mitigate | Focus trap only active when `openPanelElement !== null`; Tab cycles finite set of focusable elements; no infinite recursion |
| T-08-09 | Tampering | CSV data injection into history | medium | mitigate | Strict header validation (require Date,Duration,Cycles); type checks on parsed values (string date, number durationMs/cycles); silent skip on invalid rows |
| T-08-10 | Denial of Service | Large CSV file upload | medium | mitigate | FileReader handles synchronous text read; browser limits file size via file input UI; localStorage quota enforced by platform; oversized history capped at `maxHistoryEntries` |
| T-08-11 | Repudiation | Focus return on panel close | low | mitigate | Focus explicitly returned to opening button; ESC handler also triggers close with focus return; no silent focus loss |
| T-08-12 | Elevation of Privilege | Keyboard shortcuts while panel open | medium | mitigate | Space/R/F shortcuts disabled by `anyPanelOpen` guard; early return prevents button clicks; ESC still works to close panel |
| T-08-13 | Information Disclosure | CSV dedup shows user which sessions were skipped | low | accept | Feedback banner shows count only; no sensitive data leaked; user's own export being reimported; acceptable for UX transparency |
