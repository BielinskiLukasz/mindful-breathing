### Task 2 — Timezone-safe date arithmetic in computeStreak()

**Files:** `index.html`

**Action:**
Add a `parseLocal(str)` helper inside `computeStreak()` that constructs a local-midnight Date from a `'YYYY-MM-DD'` string using `new Date(y, m-1, d)` instead of `new Date(str)` (which parses as UTC midnight).

Replace:
```js
const dayDiff = Math.floor((new Date(today) - new Date(date)) / 86400000);
```
with:
```js
const dayDiff = Math.round((parseLocal(today) - parseLocal(date)) / 86400000);
```

Replace:
```js
const prevDate = new Date(checkDate);
prevDate.setDate(prevDate.getDate() - 1);
const prevDateStr = prevDate.toLocaleDateString('en-CA');
```
with:
```js
const prevDate = parseLocal(checkDate);
prevDate.setDate(prevDate.getDate() - 1);
const prevDateStr = prevDate.toLocaleDateString('en-CA');
```

**Verify:** `computeStreak` no longer uses `new Date(dateString)` for date-only strings

**Done:** Committed atomically with Task 1 (single commit — both changes are in the same file and functionally related)
