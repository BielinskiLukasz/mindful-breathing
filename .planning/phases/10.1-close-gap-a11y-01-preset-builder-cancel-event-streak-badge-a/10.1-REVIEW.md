## Warnings

### WR-01: Incomplete State Reset in Preset Builder Cancel Event Handler

**File:** `index.html:2060–2063`

**Issue:**

The native `<dialog>` "cancel" event listener (fired when user presses Escape) does not reset the delete button's two-step confirmation state (`_deleteConfirmed`). This creates a data loss vulnerability:

1. User clicks "Delete" → button changes to "Confirm Delete", `_deleteConfirmed = true`
2. User presses Escape to cancel instead of clicking the cancel button
3. Dialog closes, but `_deleteConfirmed` remains `true`
4. User reopens the dialog later
5. Next click on delete immediately deletes the preset without showing "Confirm Delete"

**Context:**

The explicit cancel button handler (lines 2117–2125) properly resets the state:
```javascript
presetCancelBtn.addEventListener("click", () => {
  const deleteBtn = document.getElementById("presetDeleteBtn");
  deleteBtn._deleteConfirmed = false;  // ← Resets confirmation state
  deleteBtn.textContent = "Delete";
  deleteBtn.style.background = "";
  deleteBtn.style.color = "";
  presetBuilderDialog.close();
  openPanelElement = null;
});
```

But the Escape-triggered cancel event handler (lines 2060–2063) does not:
```javascript
presetBuilderDialog.addEventListener("cancel", () => {
  openPanelElement = null;
  document.getElementById("newPresetBtn")?.focus();
  // ❌ Missing: reset deleteBtn._deleteConfirmed and styling
});
```

Similarly, when opening the edit dialog (line 2042), `_deleteConfirmed` is reset to `false`. The new preset path (line 2105) also resets it. Only the Escape path skips this cleanup.

**Fix:**

Align the cancel event handler with the explicit cancel button behavior by resetting the delete confirmation state:

```javascript
presetBuilderDialog.addEventListener("cancel", () => {
  const deleteBtn = document.getElementById("presetDeleteBtn");
  deleteBtn._deleteConfirmed = false;
  deleteBtn.textContent = "Delete";
  deleteBtn.style.background = "";
  deleteBtn.style.color = "";
  openPanelElement = null;
  document.getElementById("newPresetBtn")?.focus();
});
```
